# Implementation Plan — microplastic-detection-ml v2

Goal: a reproducible, honest, reviewer-proof repository where every number in the paper can be regenerated with one command, real and simulated data are clearly separated, and both modules (polymer imaging, scattering quantification) are validated.

Principle: **real data is labelled real, simulated data is labelled simulated** — in filenames, columns, Zenodo records, README, and the paper. Simulation is presented as a physics-based digital twin used for method development, then checked against a small set of real measurements.

## Phase 1 — Image data pipeline (Day 3–6)

### 1.1 Fetch — `src/mp/data/fetch.py`
- Download `RAW_DATASET.zip` (548 MB) from Zenodo record 21073653 to `data/raw/`.
- Verify `md5 = 5c5914a238f1fe40babb7d7a5bd1b983`; abort on mismatch.
- Extract to a fresh directory; never execute anything from it.
- Write `data/raw/manifest.csv`: `path, class, width, height, sha256, exif_datetime (if any), file_size`.

### 1.2 Audit — `src/mp/data/audit.py`
Outputs `results/data_audit.json` + figures:
- Exact duplicates (sha256).
- Near duplicates: pHash + dHash, Hamming distance ≤ 6 → union-find clusters → `group_id`.
- Per class: total files, unique groups, resolution distribution, mean brightness / per-channel means.
- **Shortcut check:** logistic regression on `[width, height, file_size, mean_R, mean_G, mean_B]` only, with GroupKFold. If accuracy ≫ 50 %, there is an acquisition confound — report it and mitigate (resize to common resolution, per-image normalisation, colour-ratio features).

Expected from the earlier audit: ~287 unique PVC groups, ~321 Nylon groups.

### 1.3 Splits — `src/mp/data/splits.py`
- Primary: `StratifiedGroupKFold(n_splits=5)` on `group_id`.
- Final hold-out: 15 % of **groups**, frozen in `data/processed/splits.json` (committed).
- If acquisition sessions are recoverable (folder names, EXIF, resolution clusters): add **leave-one-session-out** as the headline generalisation metric.
- Augmentation only inside the training fold, after splitting.

### 1.4 Pixel → µm calibration — `src/mp/imaging/calibrate_scale.py`
- Image a stage micrometer (10 µm divisions) with the 10× objective on the Pi Global Shutter camera.
- Store `um_per_px` in `configs/data.yaml`. All area features reported in µm².
- Size filter: keep particles with equivalent diameter 10–100 µm (matches stated detection range).

**Done when:** `make data audit` reproduces the counts, splits.json exists, shortcut baseline reported.

## Phase 2 — Polymer identification (Day 7–14)

### 2.1 Annotation
- First check whether `RAW_DATASET.zip` contains polygon labels.
- If not: bootstrap masks with SAM (or Cellpose) → correct in CVAT/Roboflow → export YOLO-seg format.
- Annotate only **one image per near-duplicate group** first (≈600 images), then propagate.
- Double-annotate 10 % → report inter-annotator mask IoU.

### 2.2 Baseline A — classical features + RF/XGBoost
`src/mp/imaging/segment.py`: Gaussian blur → adaptive or Otsu threshold on the green (Nile Red) channel → morphological opening → watershed split of touching particles.
`src/mp/imaging/features.py` per particle (not per image): area_um2, equivalent_diameter, perimeter, circularity, solidity, aspect ratio, eccentricity, mean/std per channel, red/green ratio, Hu moments.
- Classify **per particle**, then aggregate per image (majority / mean probability).
- GroupKFold CV; report accuracy, macro-F1, per-class P/R, confusion matrix, 95 % bootstrap CI.

### 2.3 Main model — YOLOv11-seg
`configs/yolo_seg.yaml`: `model=yolo11s-seg.pt, imgsz=640, epochs=150, patience=30, optimizer=AdamW, lr0=1e-3, seed=42`, augmentations: flips, rotate ±180°, HSV jitter (small hue range — hue carries polymer signal), scale 0.8–1.2, mosaic off for the last 10 epochs.
- Train on each GroupKFold fold → report mean ± std of mAP50, mAP50-95 (box and mask), per class.
- Hold-out set: final numbers + counting error (predicted vs annotated count per image: MAE, Bland–Altman).

### 2.4 Robustness and explainability
- Ablations: grayscale only; no colour jitter; resolution normalised vs not.
- Open-set: add an `other` class if any non-target particles exist (dust, fibres, bubbles); otherwise use max-softmax / energy score rejection and report AUROC on held-out debris images.
- SHAP for Baseline A; Grad-CAM / mask overlays for YOLO; a failure-case gallery (`results/figures/failures/`).
- Statistical comparison A vs YOLO: McNemar test on hold-out predictions.

**Done when:** `make train-cls train-seg report` regenerates every image-module number and figure in the paper.

## Phase 3 — Scattering simulator (digital twin) (Day 10–20, parallel to Phase 2)

Purpose: physically grounded data to develop and stress-test the regression pipeline before/alongside real measurements. Output is always labelled `source = simulated`.

### 3.1 Physics — `src/mp/sim/mie.py`
- Medium: water, n_m = 1.331 at 650 nm.
- Particles: PVC n ≈ 1.54, ρ = 1.38 g/cm³; Nylon-6 n ≈ 1.53, ρ = 1.14 g/cm³ (each with source in `docs/literature_params.csv`). Relative index m ≈ 1.15–1.16 — note in paper that scattering alone barely separates these polymers, which justifies the imaging module.
- Size parameter x = 2π r n_m / λ → x ≈ 64–643 for d = 10–100 µm: strongly forward-peaked Mie regime.
- Use `miepython` to compute the angular intensity |S1|² + |S2|² (unpolarised) or the correct polarisation for your laser.
- Size distribution: log-normal (median and σ from config, e.g. median 40 µm, σ_ln 0.5), integrated over 100 size bins.

### 3.2 Optics — `src/mp/sim/optics.py`
- Rig geometry from `docs/hardware/rig_geometry.md`: the **actual** detector angles θ₁…θ₄ (measure them), acceptance solid angle Ω = A_det / L², path length L_path of the cuvette.
- Concentration → number density: N = C_mass / (ρ · π d³ / 6), integrated over the size distribution.
- Single scattering: signal_i ∝ P_laser · N · L_path · ∫ (dσ/dΩ)(θ_i) Ω_i.
- Attenuation: Beer–Lambert, I = I₀ exp(−N σ_ext L) with Q_ext ≈ 2 at large x; apply to both the beam and the scattered path.
- Multiple scattering above optical depth τ = N σ_ext L > 0.1: first-order correction or a small Monte-Carlo photon transport (configurable) — this is what makes the high-concentration curve non-linear, which is the physics behind the reviewer's comment on Lasso.

### 3.3 Detector — `src/mp/sim/detector.py`
- BPW34 responsivity at 650 nm (≈ 0.4 A/W — use datasheet value), area 7.5 mm², dark current ≈ 2 nA.
- Transimpedance gain R_f (actual value from the circuit) → voltage.
- Noise: shot noise, dark current, Johnson noise of R_f, ambient-light offset, laser power drift (±1–2 %, configurable).
- ADC: **Raspberry Pi 5 has no ADC** — document the real ADC (e.g. MCP3008 10-bit, or ADS1115 16-bit). Simulate quantisation and clipping at 0 and full scale.
- Particle number fluctuation: Poisson sampling of particle count in the illuminated volume per reading.

### 3.4 Generator — `src/mp/sim/generate.py`
- Sweep: concentrations on a log grid (e.g. 0.1–10 mg/L, 30 levels) × polymers × size distributions × 5 replicates × noise seeds.
- Output `data/processed/SIMULATED_scattering_v1.csv` with columns:
  `sample_id, source=simulated, polymer, conc_mg_L, d_median_um, sigma_ln, replicate, S1..S4 (raw counts), S1..S4_volts, tau, config_hash, seed`.
- Also save `sim_config_used.yaml` alongside; Zenodo record titled "Simulated multi-angle scattering dataset (physics-based) for …".

### 3.5 Sanity checks — `notebooks/03_simulator_sanity.ipynb` + `tests/test_mie.py`
- Reproduce a textbook/published Mie phase function (e.g. Bohren & Huffman example) within tolerance.
- Low-concentration signal linear in C; roll-off at high τ.
- Forward/backward ratio increases with particle size.

**Done when:** tests pass; simulated curves are qualitatively consistent with published Mie results; every constant has a citation.

## Phase 4 — Real scattering measurements (the step that makes it publishable)

Small but real. Without this, the quantification module stays a simulation study and must be described as one.

### 4.1 Protocol — `docs/SOP_measurement.md`
- Stock suspensions: weigh sieved PVC and Nylon powder (10–100 µm fraction) on an analytical balance, disperse in filtered DI water + 0.01 % Tween-20 to avoid aggregation.
- Serial dilution: 8 levels across 0.1–10 mg/L + blank.
- 3 independent preparations × 3 readings each → ~ 8 × 2 × 9 + blanks ≈ 150 real rows.
- Record: date, temperature, laser warm-up time, dark reading before each sample, stirring.
- Reference method for a subset: microscope counting with haemocytometer or filtration + imaging → particles/mL.

### 4.2 Output
`data/processed/REAL_scattering_v1.csv` with `source=measured` and the same columns as the simulated file (where applicable).

## Phase 5 — Quantification models (Day 18–26)

### 5.1 Features — `src/mp/models/regression.py`
S1–S4 (dark-subtracted), log(S), S_mean, ratios S1/S4, S2/S4, forward/backward ratio, S_std. Handle saturated readings (flag + drop or censor).

### 5.2 Models
Lasso, Ridge, PLS, Random Forest, SVR-RBF, Gaussian Process, and a **physics-informed model** (fit the simulator's free parameters — gain, effective path length, size median — to the data via least squares, then invert for C).

### 5.3 Evaluation protocol
| Experiment | Train | Test | Purpose |
|---|---|---|---|
| E1 | simulated | simulated (held-out seeds) | pipeline works |
| E2 | simulated | real | sim-to-real gap |
| E3 | real (GroupKFold by preparation) | real | true performance |
| E4 | simulated + few real (fine-tune / calibrate) | real | value of the digital twin |

Report per experiment: R², RMSE, MAE, MAPE, 95 % bootstrap CI.

### 5.4 Analytical figures of merit (on real data)
- Calibration curve with prediction bands.
- LOD = 3.3 σ_blank / slope, LOQ = 10 σ_blank / slope.
- Linear dynamic range; repeatability (intra-day RSD) and intermediate precision (inter-day RSD).
- Recovery % on spiked tap/river water.
- Bland–Altman vs reference counting method.
- Uncertainty: conformal prediction intervals (`mapie`), report empirical coverage at 90 %.

**Done when:** `make sim train-reg report` regenerates the regression tables; E2–E4 exist (or the paper states the module is simulation-only).

## Risks

| Risk | Mitigation |
|---|---|
| Classes separable only by acquisition setup (resolution/brightness) | Shortcut baseline in Phase 1; normalise; report honestly |
| Too few unique image groups (~600) | Per-particle classification multiplies samples; report group-level CI |
| No polygon labels in the zip | SAM bootstrap + manual correction, annotate group representatives first |
| No access to the rig for real scattering data | State quantification as a simulation study; drop analytical-validation claims |
| PVC and Nylon have nearly identical refractive index | Present scattering as concentration-only; polymer ID from imaging |
