## Acquisition (as described by the authors)
Nile Red-stained particles, 365 nm UV excitation, 520 nm band-pass filter, 10× objective,
Raspberry Pi Global Shutter camera. Pixel size is **not yet calibrated** (`um_per_px: null`
in `configs/data.yaml`); sizes in `results/` are in pixels.

## Duplication (main finding)
- Group = images whose pHash Hamming distance is ≤ 6 (or identical sha256), never merged across classes.
- Every group has at least two images; mean group size is 3.35 (PVC) and 3.44 (NYLON).
- Byte-identical copies: 478 of 956 PVC and 542 of 1084 NYLON files.
- Within groups, filename numbers differ by a recurring offset — PVC top spans {'326': 110, '325': 96, '154': 76}, NYLON top spans {'543': 117, '542': 83, '532': 43} — consistent with the dataset containing each source frame more than once under different names.
- Cross-class near-duplicate pairs at the chosen threshold: 0.

## Possible acquisition confound
Classifiers that see only file metadata and global intensity (no particle information),
evaluated with group-aware 5-fold CV:

| Features | Logistic regression | Random forest |
|---|---|---|
| width, height, file size | 0.753 ± 0.040 | 0.883 ± 0.019 |
| + per-channel mean/std | 0.895 ± 0.035 | 0.971 ± 0.012 |

`acquisition_confound = true`. Class is predictable from image size and brightness alone,
so any reported accuracy must be compared with these baselines. PVC is mostly 640×480 and
NYLON mostly 742×556; PVC images are also darker on average (mean R 23.236 vs 37.708).

## Sessions
Sessions are (class, resolution) only: 2 PVC and 8 NYLON. These are a proxy, not true acquisition sessions.
Leave-one-session-out folds are therefore not emitted (needs ≥ 3 sessions per class).

## Known biases and limits
- Pristine commercial PVC and Nylon only; no weathered, aged or environmental particles.
- Two polymer classes; no "other" class for debris, fibres or other polymers.
- Laboratory conditions; single optical setup.
- Class identity is confounded with image size and brightness (see above).
- File counts overstate sample size; use group counts.

## Splits
`data/processed/splits.json`: group-level 15 % hold-out plus 5-fold StratifiedGroupKFold on the rest (seed 42). Traceability: it stores the sha256 of `groups.csv`.

## Annotation provenance (Phase 2)
- The archive has no annotations. Particle masks are **auto-generated** by the classical
  segmentation (`mp segment`): 1020 unique images, mean 34 particles per image.
- Human-corrected masks: **0** (`data/yolo/label_sources.csv`: auto 1020, corrected 0).
  Auto-vs-corrected mask IoU is therefore not available. Run `mp annotate-export`, correct,
  then `mp annotate-import` (see `docs/annotation_guide.md`), which writes
  `results/annotation_quality.json`.
- Background-only control: the particle-free background of an image predicts the class with
  0.906 balanced accuracy (`results/phase2_controls.json`).
